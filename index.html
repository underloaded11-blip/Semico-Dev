Eaglercraft Live WSS Generator & Server Configurator

Build functional WebSocket endpoints and generate the proxy setup files required to make your server run.

1. Live WebSocket (`wss://`) Generator

wss://enter-host-above.com:8081

2. Server Proxy Configuration (`listeners.yml`)

Paste this inside your `plugins/EaglercraftXServer/` or Bungeecord directory to accept incoming browser traffic.

3. Automated GitHub Action Agent

Save as `.github/workflows/eagler-agent.yml` in your GitHub repo to continuously test and check your server build architecture.
